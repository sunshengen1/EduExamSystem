# EduExamSystem 一体化教务考务成绩管理系统
[![MIT License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

## 项目简介
EduExamSystem 是一套**全闭环学籍+考务+OCR智能阅卷+多维成绩统计一体化教务管理系统**，基于 SpringBoot + Mybatis-Plus + Vue3 + Element Plus 开发。
覆盖中小学、培训机构、中职院校日常学籍建档、准考证生成、成绩导入、AI答题卡阅卷、多维度成绩统计、系统安全管控全业务流程，功能全部落地可用、开箱部署。

## 技术栈
### 后端
- SpringBoot 2.7.x
- MyBatis-Plus 3.5.x
- ZXing（二维码解析）、PaddleOCR（答题卡识别）、FastJSON、Apache POI
- MySQL 8.0+

### 前端
- Vue3 + CompositionAPI
- Element Plus、Axios

## 核心功能清单
### 1.学籍档案管理
1. 学部、年级、班级、教师、学生5类基础档案Excel批量导入/导出；
2. 学生信息：姓名、学号、准考证、校区、考场、座位、入学日期、院校编码、学制编码全字段管理；
3. **自研6分段自定义准考证引擎（项目特色）**
   - 自定义规则：入学年份+院校+学制+校区+考场+座位六段编码，自由配置每段长度、起始位置；
   - 单条/批量生成准考证、准考证反向解析自动回填学生信息；
   - 按考场批量导出花名册、分考场打包ZIP压缩包。

### 2.成绩录入模块
1. 总分Excel、单科成绩Excel导入；
2. 匹配优先级：**准考证优先匹配，无准考证自动使用学号匹配**；
3. 支持OCR答题卡识别自动批量入库成绩。

### 3.OCR智能答题卡阅卷（核心亮点）
1. 后台配置考试科目标准答案、**客观题每题独立分值（每题分数可不一致）**；
2. 答题卡照片上传：
   - ZXing识别二维码自动提取准考证，识别成功锁定输入框，失败手动补充；
   - OCR识别客观填涂答案，系统逐题判分，自动汇总客观总分；
3. 弹窗查看客观小题明细：题号、标准答案、学生作答、单题得分；
4. 人工录入主观题得分，自动计算：`单科总分=客观得分+主观得分`；
5. OCR全流程日志归档：保存图片名称、准考证、小题明细、入库状态，历史记录可查询回溯；
6. 入库前置校验：空准考证拦截，一键批量入库，数据实时同步全部统计报表。

### 4.27套全维度成绩分段统计报表
> 统一分段：优秀/优良/及格/低差 + 总人数 + 加权得分，全报表支持多条件筛选+Excel导出，榜单额外支持PDF导出
1. 原有18套基础成绩排名报表；
2. 新增9套专项统计表：
   - 考场总分统计、院校学制总分/单科统计；
   - 年级班级单科/总分统计、校区考场单科/总分统计；
   - 全校总分汇总、全校单科汇总；
3. 筛选条件：考试ID、学部、校区、考场、年级、班级、科目、入学年份、院校/学制编码自由组合筛选。

### 5.考务可视化与阅卷管控
1. 成绩分段分布柱状图、阅卷进度柱状统计图；
2. 全局阅卷启停开关，关闭状态禁止Excel/OCR成绩入库。

### 6.系统安全设置模块
1. 密码策略：自定义最小密码长度、开启/关闭密码复杂度（大小写+数字+特殊符号）；
2. 登录防爆破：密码错误N次锁定账号、自定义锁定时长；
3. IP白名单：开启后仅白名单IP可登录系统；
4. 全系统操作日志：登录、新增、修改、删除、OCR上传、数据导出全操作留痕可查。

### 7.配套辅助功能
1. **新手分步引导**：管理员后台按页面配置引导文案、DOM锚点、提示弹窗位置；用户首次进入页面自动弹出引导，完成后不再重复弹窗；
2. **用户服务协议**：管理员后台编辑协议内容、开关弹窗；用户首次登录必须勾选同意协议才可进入系统，协议内置【第三方开源软件版权声明】。

### 8.全类型导出
Excel/PDF成绩榜单、准考证清单Excel、分考场花名册ZIP压缩包、全部统计报表Excel。

## 快速部署教程
### 环境要求
- JDK8 / JDK11
- MySQL8.0及以上
- Maven3.6+、Node.js 16+

### 部署步骤
1. 克隆项目代码；
2. 执行 `doc/sql/init.sql`，初始化数据库表结构与基础数据；
3. 修改后端yml配置文件内MySQL连接地址、账号密码；
4. Maven打包/直接启动SpringBoot后端项目；
5. 前端目录执行：`npm install && npm run dev`；
6. 默认超级管理员账号：`admin` / `123456`，可在系统安全设置修改密码规则。
